Honesty labels (per WO-P5-RELEASE decision 4)

  • FPS: P99 is the headline; absolute numbers are sandbox-Python-interpreted so they're low; the comparison across backends is the signal.
  • alloc/frame: tracemalloc measures Python-side allocations; ctypes-level copies are not counted. C and D assert 0 (RED on violation).
  • GC pauses: count via gc.get_stats() collection delta; pause duration not tracked by Python's gc module (reported as 0 with a note).
  • CPU%: (process_time delta / wall_time delta) * 100 — captures interpreter + GC overhead.
  • cold-start: time from backend __init__ to first publish return.
