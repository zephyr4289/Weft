# Acceptance — Definition of Done, Evidence, Failure Protocol

**Normative for sign-off.** "Done" is evidence, not effort (roadmap §"one rule"). A phase that claims green without producing the artifacts has not finished.

---

## 1. Gate G0 — Environment (before Step 1)

- [ ] Pre-flight probes pass (06 §1): gcc, make, rustc ≥ 1.7x (freshly installed per A7), node ≥ 24 (TS-strip + SAB + exchange + workers), python3 ≥ 3.12
- [ ] Probe transcript pasted into the work log

## 2. Gate G1 — C reference (before any other language)

- [ ] `core/c` compiles warning-clean (`-Wall -Wextra`, no suppression flags)
- [ ] All 8 tests exit 0 individually, then via the driver: **8/8 cells**
- [ ] Review checklist (06 §7) signed against the C sources
- **Only now may Rust/TS begin** — C is the reference semantics the other two must reproduce.

## 3. Gate G2 — Full matrix (the product)

- [ ] **24 cells green × both build modes** (C debug+release, Rust debug+release, TS) — 40 driver invocations, all exit 0
- [ ] `litmus/REPORT.md` generated by the driver: matrix complete, environment captured, honesty label `x86_64-sandbox (runtime-verified)` present
- [ ] `litmus/results.json` bundle present (raw verdicts + stderr on any prior reds kept as evidence)
- [ ] L1: `torn=0` for holds 5/10/50 ms in **all three languages independently**
- [ ] L2/L3: `max_steps ≤ 2` on **release** builds (debug bounds are necessary but release is the gate)
- [ ] L4: `drain_exact == true` in all three languages
- [ ] L6: seed `0x00C0FFEE` recorded; schedules identical; violations 0
- [ ] L7: `poison_intact` and `reclaim_ok` true everywhere
- [ ] L8: all four subchecks true everywhere
- [ ] Cross-language rule (A6): zero unexplained divergences

## 4. Gate G3 — Hardening

- [ ] TSAN column run (06 §6): clean, or findings filed with the report attached
- [ ] `make clean && make litmus` reproduces the full green matrix from a fresh checkout — **the reproducibility run**, timed and recorded

## 5. Evidence bundle (deliver with the PR)

| Artifact | Location |
|---|---|
| Kernel + runner sources ×3 | `core/{c,rust,ts}/` |
| Catalog + validator | `litmus/catalog.yaml`, `tools/validate_catalog.py` |
| Generated report + raw results | `litmus/REPORT.md`, `litmus/results.json` |
| Driver | `tools/litmus_driver.py` |
| Pre-flight + TSAN transcripts | `litmus/evidence/` (plain text logs, timestamped) |
| Review checklist signatures | PR description (06 §7 per language) |

## 6. Failure protocol (non-negotiable)

1. **A red test is information.** Freeze the params + seed, capture stderr, file a finding with the repro command. No tolerance edits, no re-run-until-green, no sleep injections.
2. **Divergence triage order** (A6): (a) reproduce in the red language alone; (b) check 06 §5 registry; (c) diff the kernel against 02 §2/§5 line-by-line; (d) only then suspect the spec — and file a spec bug rather than localizing a workaround.
3. **Protocol bug found = suite working as designed.** The founding spec's §5 was killed by exactly this process; L1–L8 red on a real race is a first-class Phase 0 outcome, not a missed deadline. Report it up with the same weight as a green matrix.
4. **Slippage is published**: if G2 slips, the report header carries `STATUS: SLIPPED (reason)` — never a silent scope cut.

## 8. Explicitly out of scope for this phase (do not build)

Kotlin/Swift/Dart sources · Steward/Heddle layers · benchmark harness (Phase 1) · weft-probe/record (Phase 2) · whitepaper (Phase 3) · browser publishing, Maven/npm/pub.dev (Phase 6+) · Pro tier (out of scope, charter clause 4). Anything here sneaking into a Phase 0 PR = scope creep, reject.
