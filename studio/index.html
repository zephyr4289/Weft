WEFT STUDIO · PILLAR 7 · v1 SHIPPED

See the machine.

A continuous-state system deserves a continuous-state tool. Weft Studio is an Android-Studio-grade visual suite for the zero-copy ecosystem — and it dogfoods the very protocol it inspects: its own hot plane runs at 240 FPS through @weft/react-heddle, and its React tree re-renders exactly once per mount. The product ships its own X-ray machine.

  • zero-dependency engine
  • Tauri desktop shell
  • sub-15 MB bundle target
  • audits D-71 · D-72 · D-73

THE CONSTITUTION, APPLIED TO THE IDE ITSELF

The Two-Plane Law · STUI1

COLD PLANE · studio chrome

Reactive. Normal. Allowed to re-render.

Menus, settings, file trees, theme — ordinary React state at human pace. Invalidated by user intent, diffed, patched. Exactly what frameworks were built for.

ONE RULE BETWEEN THEM

HOT PLANE · monitors, traces, gauges

Draw-phase only. One render per mount. Ever.

Every live readout claims a Triad buffer and paints it in the draw phase. A second render of a HOT component is not slow — it is a law violation, caught by the Render Spy and failed in CI.

THE SIX PANELS

An instrument wall with opinions.

Each panel is a seam contract from STUDIO-SEAMS-V1 — versioned, testable, and honest about what it shows.

01

ENGINEER-2 SEAM

Ring Monitor

Maps the raw seqlock memory region — 1,000,000 slots × 32 bytes — and decodes every field live: seq parity, writer lane, msg_type, timestamps, payload. This is not a log viewer; it reads the same bytes the kernel reads, zero-copy, through the inspector seam.

  • 1 M slots × 32 B map
  • field-level decode
  • parity tripwires
02

STUI1 ENFORCEMENT

Render Spy

The Two-Plane Law made visible: HOT components must render exactly once per mount. The Spy instruments the heddle runtime and flags any second render of a hot component as a law violation — in the editor, in CI, and in production builds that opt in.

  • renders == 1 · enforced
  • violations fail the build
  • ships inside @weft/react-heddle
renders: 1✓ STUI1
03

SREC1 SIDECAR

Time-Travel Flight Recorder

.weftrec files record ring commits with monotonic timestamps. The debugger scrubs backward and forward through real state — O(log n) seek over CRC-32C-checksummed frames. Deterministic replay across languages is tested in CI (record in C, replay in TS).

  • O(log n) seek
  • CRC-32C framed
  • cross-language replay
⚑
04

LAW-4 TAXONOMY

Cache-Line Inspector

Live view of 64-byte cache lines across hot structures, with false-sharing tripwires. When two writers land on one line, the Inspector says so — before your p99 does.

  • 64 B line resolution
  • false-sharing alarms
  • pads audited against STUDIO-SEAMS §6

ENGINEER-1 SEAM

Schema Editor · weft-lsp + weftc-WASM

A language server for .weftc schema files plus a WASM build of the compiler — full validation, completion and codegen with zero install. It runs in this browser tab and in the desktop shell identically.

06

DROP-NOT-QUEUE

Cadence Governor

Studio UI updates are governed to 240 Hz with a hard budget: p99 ≤ 4.166 ms. Under pressure the governor drops frames rather than queueing them — the same policy the kernel teaches, applied to the tool itself.

  • 240 Hz target cadence
  • drop-not-queue
  • budget asserted in D-72
